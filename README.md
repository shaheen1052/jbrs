# JB Reporting System (JBRS)

Online in-house reporting for Janata Bank PLC., Sirajganj Area.

- Branches log in with their branch code, enter reports and submit them.
- The Area Office (5038) sees all 24 branches, returns reports for correction, consolidates them,
  and downloads them as Excel.
- Includes the Interest Waiver Calculator, with Annexure-Ga and Annexure-Gha for many borrowers.

Cloudflare Pages settings: build command empty, build output directory `site`,
D1 database binding `DB`.
